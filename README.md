## 🧩 List of Problems

1.  **Reverse a String**  
    Reverse the given string.

2.  **Count Vowels in a String**  
    Count the number of vowels (a, e, i, o, u).

3.  **Check for Palindrome**  
    Check whether a string reads the same forward and backward.

4.  **Find the Maximum Number**  
    Find the largest number in an array.

5.  **Remove Duplicates from an Array**  
    Remove duplicate numbers from an array.

6.  **Sum of All Numbers in an Array**  
    Calculate the total sum of numbers in an array.

7.  **Find Even Numbers in an Array**  
    Return only even numbers from an array.

8.  **Capitalize First Letter of Each Word**  
    Capitalize the first letter of every word in a string.

9.  **Find the Factorial of a Number**  
    Calculate the factorial using a loop.

10. **PingPong Challenge**  
    Print numbers from 1 to 20 with the following rules:
    - Multiples of 3 → `Ping`
    - Multiples of 5 → `Pong`
    - Multiples of both → `PingPong`
